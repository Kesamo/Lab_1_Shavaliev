# Дизайн программы для работы с AVL-деревом

## 1. Постановка задачи

Цель работы — создать программу для хранения и обработки значений в AVL-дереве. Пользователь может добавлять и удалять значения, искать их, просматривать в разных порядках, а также сохранять структуру дерева в строковом виде и восстанавливать её.

Программа может служить основой для справочников, индексов и других систем, где данные часто меняются и требуется быстрый поиск. Библиотечная часть рассчитана на разные типы сравнимых значений; консольный интерфейс данной работы использует целые числа.

## 2. Сущности прикладной задачи

- **Значение** — отдельный элемент, который хранится в дереве. В одном дереве находятся значения одного типа.
- **AVL-дерево** — структура для хранения уникальных значений с поддержанием порядка и баланса.
- **Правило сравнения** — определяет, какое из двух значений меньше, и позволяет выявлять равные значения.

## 3. Архитектура

Программа состоит из трёх основных частей:

1. **Консольный интерфейс** принимает команды пользователя и показывает результаты.
2. **Логика AVL-дерева** выполняет операции над значениями и поддерживает порядок и баланс.
3. **Компонент последовательности** предоставляет результат обхода в виде последовательности значений для вывода или дальнейшей обработки.

Консольный интерфейс передаёт команды и значения логике AVL-дерева. Дерево возвращает результат операции или строковое представление. При обходе значения передаются в компонент последовательности, после чего интерфейс выводит их пользователю.

### Основные решения

**Структура данных.** AVL-дерево является бинарным деревом поиска: значения, меньшие по правилу сравнения, находятся в левом поддереве, большие — в правом. Это свойство поддерживается при каждой операции, а не возникает после обхода. Разница высот левого и правого поддеревьев для каждого узла не превышает единицу.

**Изменение дерева.** После вставки или удаления обновляются высоты затронутых частей дерева. Если баланс нарушен, выполняется один или два поворота. Благодаря балансу поиск, вставка и удаление требуют времени порядка `O(log n)`.

**Обходы.** Пользователь может задать порядок посещения корня, левого и правого поддеревьев. Предусмотрены шесть порядков: КЛП, КПЛ, ЛКП, ЛПК, ЛПК, ПЛК и ПКЛ. Здесь К — корень, Л — левое поддерево, П — правое поддерево. Обход ЛКП выдаёт значения по возрастанию согласно правилу сравнения, не изменяя дерево.

**Обработка значений.** На основе обхода предусмотрены преобразование значений (`map`), отбор по условию (`where`) и свёртка в один результат (`reduce`). Преобразование и отбор создают новые деревья.

**Строковое представление.** Дерево можно преобразовать в строку с сохранением его структуры, а затем восстановить из этой строки. При восстановлении проверяются корректность записи, порядок значений и баланс дерева. Строка, сохранённая через консольный интерфейс, доступна в течение текущего запуска программы.

## 4. Функциональные требования

### К AVL-дереву

1. Добавлять значение. Если равное значение уже есть, дерево не изменяется.
2. Удалять значение. Если значение отсутствует, дерево не изменяется.
3. Проверять наличие значения.
4. Сообщать количество значений, высоту дерева и признак пустого дерева.
5. Очищать дерево.
6. Поддерживать свойства бинарного дерева поиска и AVL-баланс после вставки и удаления.
7. Выполнять обход в любом из шести заданных порядков.
8. Преобразовывать, отбирать и сворачивать значения.
9. Преобразовывать дерево в строку и восстанавливать его из строки. Некорректная строка должна вызывать сообщение об ошибке; ранее существовавшее дерево при этом сохраняется.

### К консольному интерфейсу

1. Предлагать команды вставки, удаления, поиска, просмотра дерева и выбора обхода.
2. Выводить результат операции: например, добавлено ли значение или найдено ли оно.
3. Позволять сохранить строковое представление дерева и восстановить дерево из введённой или ранее сохранённой строки.
4. Позволять добавить заданное количество случайных целых чисел и очистить дерево.
5. Сообщать об ошибках ввода и продолжать работу после них.
6. Показывать текущие количество значений и высоту дерева.
